# Google Home setup

Use the [Google Home Developer Console](https://console.home.google.com/) and create a Cloud-to-cloud integration. The supported intent surface is SYNC, QUERY, EXECUTE and DISCONNECT. OAuth uses authorization-code flow. Paste the exact values generated by bootstrap and deploy; a one-character redirect difference causes linking to fail.

Virtual `SWITCH` devices use OnOff and return `on: false` on QUERY. Mute and transport are momentary switches. Official media types require MediaState plus proactive Report State, so numeric volume remains in the local dashboard until a HomeGraph service account is provisioned. Google Home does not provide a custom process-list/CPU-temperature dashboard; those are intentionally not claimed. Report State is not enabled in this private v1; QUERY is authoritative.

Use the values produced in `generated/google-home-values.txt`. Keep **HTTP Basic Auth off**, save the integration, then open **Cloud-to-cloud → Test** and click **Test** once.

Private test path: Google Home → Add → Device. If the QR scanner appears, choose **Add a different way**, then search for **`[test] HomePC`**. QR commissioning is Matter-only and is not used by HomePC v1.
