# Google Home setup

Use the [Google Home Developer Console](https://console.home.google.com/) and create a Cloud-to-cloud integration. The supported intent surface is SYNC, QUERY, EXECUTE and DISCONNECT. OAuth uses authorization-code flow. Paste the exact values generated by bootstrap and deploy; a one-character redirect difference causes linking to fail.

Virtual `SWITCH` devices use OnOff and return `on: false` on QUERY. Mute, transport and custom routines are momentary switches. Numeric volume remains in the local dashboard. HomePC v2 supports optional Home Graph Report State after a matching service account is configured. Google Home does not provide a custom process-list or CPU-temperature dashboard, so those are intentionally not claimed.

Use the values produced in `generated/google-home-values.txt`. Keep **HTTP Basic Auth off**, save the integration, then open **Cloud-to-cloud → Test** and click **Test** once.

HomePC v2 can expose custom routines as additional momentary switches. It also implements optional Home Graph Report State after the matching service-account credentials are uploaded with `tools/configure-report-state.ps1`; without those Worker secrets, QUERY remains authoritative.

Private test path: Google Home → Add → Device. If the QR scanner appears, choose **Add a different way**, then search for **`[test] HomePC`**. QR commissioning is Matter-only and is not used by HomePC.
